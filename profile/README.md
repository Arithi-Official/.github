Arithi gives students hands-on STEM: coding, future skills, school clubs and interschool competitions. Every student gets a stage to build things, compete, and show what they can do beyond a report card.

### What we build

- **Learning:** coding and future-skills tracks for school students.
- **Clubs:** hands-on STEM clubs that run inside schools.
- **Competitions:** interschool STEM contests, hackathons and olympiads.
- **Student dashboard:** progress, achievements and a portfolio that grows with every challenge.
